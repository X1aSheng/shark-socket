## 2. 连通性验证

安全组未放行时端口探测呈 filtered，放行后在 srv3 启动监听器，srv2 探测结果:

```text
18000 CONNECT_OK
19000 CONNECT_OK
```

说明此前 filtered 属无监听服务导致的误判，非安全组阻断。

双向 ping（srv2 -> srv3）:

```text
5 packets transmitted, 5 received, 0% packet loss
rtt min/avg/max/mdev = 43.154/43.266/43.583/0.159 ms
```

RTT 与隧道方案基本一致（43.2 ms），路径未变化。

## 3. 直连链路带宽（iperf3，srv3 服务端 19000 端口）

| 场景 | 接收端速率 | 备注 |
| --- | --- | --- |
| TCP 单流上行 | 97.9 Mbps | 单连接接近公网上限 |
| TCP 4 流上行 | 108 Mbps | 多流可小幅超越单流 |
| TCP 下行 | 97.3 Mbps | 上下行基本对称 |
| UDP 80 Mbps | 79.5 Mbps，0% 丢包，抖动 0.014 ms | 未触顶 |
| UDP 95 Mbps | 94.5 Mbps，0% 丢包，抖动 0.014 ms | 未触顶 |
| UDP 120 Mbps | 111 Mbps，6.6% 丢包 | 已超过 100 Mbps 合同带宽 |

结论: TCP 实际可用约 97-108 Mbps，符合 100 Mbps 峰值标称；UDP 在 95 Mbps 以内零丢包。

## 4. 网关跨主机压测（srv2 直连 srv3:18000）

| 场景 | 连接 | 请求 | 错误 | 吞吐 | 净荷带宽 | p50 | p95 | p99 | max |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| conn1-64B | 1 | 500 | 0 | 16.4 req/s | 0.008 Mbps | 60.67 ms | 60.76 ms | 60.97 ms | 61.99 ms |
| conn10-64B | 10 | 2000 | 0 | 163.2 req/s | 0.084 Mbps | 51.91 ms | 60.91 ms | 60.99 ms | 70.84 ms |
| conn50-64B | 50 | 5000 | 0 | 758.1 req/s | 0.388 Mbps | 52.38 ms | 62.29 ms | 65.08 ms | 74.67 ms |
| conn100-64B | 100 | 5000 | 0 | 1545.8 req/s | 0.791 Mbps | 51.73 ms | 61.92 ms | 63.03 ms | 73.12 ms |
| conn100-1KB | 100 | 5000 | 0 | 1467.3 req/s | 12.02 Mbps | 52.62 ms | 62.07 ms | 66.56 ms | 68.85 ms |

合计 16500 次请求，错误 0。

延迟结构: p50 约 52 ms = 一个 RTT（43 ms）+ 应用处理与排队；p95/p99 抬升到 60-66 ms，主要来自公网排队与重传，属于跨主机同步请求的固有抖动，非网关处理瓶颈（网关侧 CPU 峰值 3.6%）。

## 5. 直连与隧道方案对比

| 指标 | SSH 隧道（基线） | 公网直连 | 变化 |
| --- | --- | --- | --- |
| 100 并发吞吐 | 1778.8 req/s | 1545.8 req/s | -13.2% |
| 100 并发 p50 | 53.99 ms | 51.73 ms | -4.2% |
| 100 并发 1KB 净荷 | 未记录 | 12.02 Mbps | - |
| 错误数 | 0 | 0 | 一致 |
| 会话回收 | 全部回收 | 全部回收 | 一致 |

吞吐略低于隧道基线属正常: 隧道基线为 srv2 本地回环连接 srv2 上的桥接进程，链路更短；直连路径含完整公网 RTT 与运营商排队。直连 p50 略优，说明去掉桥接层转发确实削减了一次本地排队。

## 7. 可重入性

压测完成后网关指标:

```text
sessions_accepted_total 261
sessions_closed_total 261
sessions_active 0
```

接受数与关闭数完全相等，活跃会话归零，无泄漏、无残留 fd。容器 PID 数在压测前后保持 9不变，验证程序可重复进入并稳定回收。

## 8. 结论

1. 安全组放行 18000/19000 后，srv2 可直连 srv3 网关，无需 SSH 隧道或桥接层。
2. 公网直连 RTT 43.27 ms，双向零丢包，TCP 实际吞吐 97-108 Mbps，符合 100 Mbps 标称。
3. 网关在 100 并发跨主机同步场景下达 1465-1546 req/s，16500 请求零错误，p50 约 52 ms。
4. 网关资源占用极低（CPU 峰值 3.61%，内存约 3 MiB），具备充足横向扩展余量。
5. 会话计数严格配平，可重入性在跨主机真实链路下依然成立。
